📚 ResearchMind — AI-Powered Research Paper Assistant

ResearchMind is an AI-powered research assistant that helps users explore and understand research papers through natural-language conversations. Built using Retrieval-Augmented Generation (RAG), it retrieves relevant information from uploaded PDF documents and uses a Large Language Model (LLM) to generate context-aware answers.

The application combines LangChain, FAISS, HuggingFace Embeddings, Groq, and Streamlit to provide a conversational interface for interacting with research documents. It also supports conversation history and source-page references, helping users trace answers back to the uploaded papers.

Key Features

PDF Upload: Upload research papers for processing.

Semantic Search: Find relevant document chunks using embeddings and FAISS.

Context-Aware Answers: Generate answers grounded in retrieved document content.

Conversation History: Ask follow-up questions without repeating the entire context.

Source Citations: Display source PDF filenames and page numbers for retrieved content.

Interactive Interface: Ask questions through a Streamlit web application.

Objective

The goal of ResearchMind is to make research papers easier to explore by combining document retrieval, LLM-based question answering, and conversational interaction in a single application.
